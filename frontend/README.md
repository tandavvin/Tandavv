# Tandav frontend

React + Vite + Tailwind CSS v4. See the project README one level up for setup, features and the project map.

```bash
npm install
npm run dev      # http://localhost:5173
npm run lint
npm run build
```

Set `VITE_API_URL` in `.env` if the API is not on `http://localhost:5000` (see `.env.example`).
